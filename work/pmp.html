01쓰던 한글 문제 파일로
시험을 준비합니다

문제지와 정답지를 HWPX 파일로 등록합니다. 불러온 문항과 정답을 확인해 문제 세트로 저장하고, 시험을 만들어 반별로 배정합니다.

아래 다섯 단계는 같은 예시 시험 ‘고1 영어 · 독해와 어법’을 따라갑니다. 실제 제품에 가상 이름·문제·성적을 넣어 촬영했으며, 학생 화면은 Flutter 앱의 웹 실행 화면입니다.

파일에서 불러온 문항 확인하기

시험을 보고, 결과를 확인하고
틀린 문제를 다시 풉니다

선생님이 등록한 문제가 학생 앱으로 이어집니다. 답안을 제출하면 채점 결과를 확인하고, 오답노트에서 틀린 문제를 다시 풀며 이유를 남깁니다.

02학생 응시

지문 속 표현을 선택해 답안을 제출합니다.

03결과 확인

6문항 중 4문항 정답. 틀린 2·5번 문항을 확인합니다.

04오답노트

틀린 문제를 다시 풀고, 놓친 부분을 메모합니다.

다른 문제 유형의 응시 화면 보기

지문형 선택·빈칸 외에도 문장 배열, 단어 배열, 서술형 영작에 맞는 입력 방식을 구현했습니다.

옆으로 넘겨 다른 문제 유형을 볼 수 있습니다.

05선생님은 답안과 복습 기록을
한 화면에서 확인합니다

강사 콘솔의 응시 상세 화면에서 학생의 점수, 응시 시간, 문항별 답안과 정오를 확인합니다. 학생이 오답노트에 남긴 메모도 해당 문항에 함께 표시됩니다.

앞서 본 학생의 4/6점 결과와 2번 문항의 오답, 과거형에 관한 복습 메모가 그대로 이어집니다.

OMR · 종이 시험에서 성적표까지

종이 문제지로 시험을 보면서 앱으로 답안을 제출할 수 있습니다. 강사는 웹에서 제출·채점 상태를 확인하고, 영역별 분석이 담긴 OMR 성적표를 확인합니다.
