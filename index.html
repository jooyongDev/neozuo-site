진행 절차

상담 후 개발 범위와 비용, 일정을 정합니다.

자주 묻는 질문 보기

  1. 상담

    만들고 싶은 서비스와 현재 상황을 듣고, 검토에 필요한 자료를 안내합니다.

  2. 개발 범위·견적 협의

    개발할 기능과 결과물, 비용·일정, 공유·검수 방법을 함께 정합니다.

  3. 개발·검수

    합의한 범위에 따라 개발하고 결과물을 확인합니다. 변경 요청은 반영 전에 협의합니다.

  4. 출시·인수인계

    검수를 마치면 배포와 인수인계를 진행합니다. 이후 지원은 계약한 범위에 따릅니다.

자주 묻는 질문

기획서가 없어도 문의할 수 있나요?

네. 만들고 싶은 서비스를 간단히 설명해 주세요. 필요한 기능과 개발 순서를 정리하는 기획 서비스도 제공합니다.

기존 코드가 있는 프로젝트도 맡길 수 있나요?

네. 현재 코드와 서비스 상태를 확인한 뒤 추가하거나 수정할 기능과 개발 방법을 협의합니다.

견적과 작업 범위는 어떻게 정하나요?

서비스의 목적과 필요한 기능, 기존 자료, 예산과 희망 일정을 확인해 견적을 안내합니다. 기획이나 코드 검토가 먼저 필요하다면 해당 작업의 범위와 비용부터 협의합니다.

진행 상황은 어떻게 확인하나요?

진행 상황을 얼마나 자주, 어떤 도구로 공유할지 개발 시작 전에 정합니다. 개발한 기능을 직접 확인하는 방법도 함께 안내합니다.

개발 중 요구사항이 바뀌면 어떻게 하나요?

기존 개발 범위에 포함된 요청인지 먼저 확인합니다. 추가 작업이 필요하면 비용과 일정이 어떻게 달라지는지 논의한 뒤 반영할 내용을 정합니다.

출시 후에는 어떤 지원을 받을 수 있나요?

개발한 기능의 오류 수정과 운영 관리, 새로운 기능 개발을 구분해 안내합니다. 지원 범위와 기간, 요청 접수와 처리 방법은 계약할 때 정합니다.
