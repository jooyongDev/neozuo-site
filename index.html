진행 방식

고정 비용 기획 스프린트 · 단계별 견적 · 끝이 보이지 않는 과금 없음

  1. 1단계 · 1–2주

    기획 스프린트

    아이디어를 실행 계획으로 바꿉니다. 기능 목록, 사용자 흐름 또는 클릭 가능한 프로토타입, 기술 방향, 단계별 견적과 일정을 고정 비용으로 정리해 드립니다.

  2. 2단계 · 4–12주 단위

    단계별 개발

    디자인 → 개발 → 테스트 → 출시. 단계마다 범위를 확정하고, 매주 진행 상황을 공유합니다.

  3. 3단계 · 월 단위

    운영·유지보수

    오류 수정, 모니터링, OS·라이브러리 업데이트, 그리고 매달 기능 개선에 쓸 수 있는 개발 시간.

진행이 멈춘 프로젝트가 있나요?

프로젝트 인수·정상화 — 1주 동안 코드와 진행 상황을 점검하고, 정상화 계획을 세운 뒤 개발 또는 운영으로 이어갑니다.

자주 묻는 질문

학원관리 프로그램을 쓰면 되지 않나요?

출결·수납이 잘 된다면 그대로 쓰셔도 됩니다. 저희는 기존 프로그램이 해주지 못하는 것, 즉 우리 학원만의 브랜드 경험, 커리큘럼에 맞춘 기능, 시스템 연동을 만듭니다.

작은 팀에 맡겨도 괜찮을까요?

고정 비용의 기획 스프린트로 작게 시작해 보세요. 개발에 들어가면 매주 진행 상황을 직접 확인하실 수 있습니다. 저희가 만든 교육 서비스 사례도 확인해 보세요.

비용은 어떻게 정해지나요?

기획 스프린트는 고정 비용입니다. 개발은 기획 결과를 바탕으로 단계별 견적을 드리며, 시간당 과금은 하지 않습니다. 상담에서 프로젝트에 맞춰 안내해 드립니다.

진행 상황은 어떻게 알 수 있나요?

개발 기간 동안 매주 데모 또는 진행 보고를 드리고, 개발자와 직접 소통하실 수 있습니다.

출시 후 문제가 생기면요?

월 단위 운영·유지보수로 오류 수정, 업데이트, 기능 개선을 계속 맡습니다.

교육 분야가 아니어도 되나요?

네. 교육은 저희의 전문 분야일 뿐 한계가 아닙니다. 웹·앱·백엔드·AI 개발 모두 문의하세요.
